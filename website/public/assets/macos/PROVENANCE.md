# Native application icons

These PNGs are rendered from the official application icon resources installed on macOS 27.0.1 (build 26A434). They are shown only as illustrations of the Mac applications inside the product preview, not as Notchy branding or an endorsement. Apple retains its rights in its application icons.

- Finder: /System/Library/CoreServices/Finder.app/Contents/Resources/Finder.icns
- Safari: /Applications/Safari.app/Contents/Resources/AppIconUpdated.icns
- Music, Calendar, Notes, Photos, Messages, Mail, Reminders: their CFBundleIconFile resources in /System/Applications.
- Xcode: /Applications/Xcode.app/Contents/Resources/Xcode.icns
- System Settings: /System/Applications/System Settings.app/Contents/Resources/Settings.icns
- Folder: /System/Library/CoreServices/CoreTypes.bundle/Contents/Resources/GenericFolderIcon.icns
- Notchy: the built app's Contents/Resources/AppIcon.icns, matching the project's Assets/AppIcon/AppIcon.icns.
- Apple menu glyph: the installed system symbol apple.logo, rasterized locally.

The Notchy icon remains the project's own asset. The landscape images in ../img are original generated artwork.
